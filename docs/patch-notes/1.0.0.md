# Cryovanta Protocol `1.0.0` Patch Notes

**Build Status:** `1.0.0-rc1` (Headless Simulation & Android Export Config Ready; Physical Hardware Sign-off `NOT ASSESSED`)

## Highlights

- **Exterior Terrain Visibility & Compute Parity:** Cryo-planet surfaces now render externally via double-sided surface shading (`cull_disabled`) with signed elevation rock-to-glacier blending, CPU↔GLSL simplex sector `i2z` alignment, preallocated scratch buffers (`_twx_pool`), continuous polar wind vectors, finite bound freefall apsides, and same-tick collider transform rebase syncing.
- **Coherent Sortie Progression, Rewind & Restart:** Wave spawning respects Recon/Intercept/Landing sortie stages, enemy evasion respects an orbital/range leash, `MODE_SOFT_LAND` scales braking authority to live vessel wet mass, and landing completion requires `0.15 s` sustained surface contact. Pilots can pause anytime (`P` / `ESC` / `Start`), rewind coherently (`R` / `REWIND` / `X`), or perform zero-leak sortie restarts (`BACKSPACE` / `Back`).
- **HUD, Touch & Gamepad Ergonomics:** Enabled responsive `canvas_items`/`expand` viewport scaling, numeric telemetry readouts (`ALT`, `RAD`, `V/S`, `SPD`, `G`, `FUEL`, `SCORE`), named guidance modes, non-color `[!]`/`[!!]` traffic vs terrain warnings, explicit `OVERHEAT` lockout badges, zero-overlap `[344, vw - 214]` top touch action buttons, and idempotent gamepad fallback mappings.
- **Audio & Telemetry:** Added allocation-free procedural cockpit sound synthesis (`PlanetaryEnvironment`, muted in headless runs) and microsecond step-timing telemetry (`SimulationTelemetry`) verified across 36 headless test suites.

## Known Hardware Validation Scope

Automated verification covers headless deterministic simulation on macOS; real Android ARM64 / Vulkan Mobile (`Adreno 840`) frame pacing, thermal soak, and Google Play signed `.aab` packaging remain `NOT ASSESSED` until on-device testing runs.
